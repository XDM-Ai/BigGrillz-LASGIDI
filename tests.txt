# Tests

## Test 1 - Navigate from hero to menu and start an order [sanity]
Viewport: mobile
Covers: hero CTA navigation, specialties section, WhatsApp order CTA, mobile-first interaction
Description: Verifies the primary visitor journey from the hero into the menu and onward to ordering.
Steps:
1. Load the homepage at a mobile viewport.
2. Tap "VIEW MENU".
3. Tap an "ORDER NOW" link in the specialties section.
Expected: The page smoothly reaches the specialties section, and the order action points to the BigGrillz WhatsApp ordering URL.

Viewport: desktop
