# BigGrillz LASGIDI

Premium mobile-first website for BigGrillz LASGIDI — a Nigerian virtual restaurant specializing in bole, roasted plantain, charcoal-grilled fish and signature pepper sauce.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Notes

- Replace the placeholder Instagram, Facebook and TikTok destinations in `src/main.ts` when the official handles are available.
- Replace the Glovo and Chowdeck platform links with the restaurant's direct listing links when available.
- No prices, address, opening hours or delivery areas have been invented.


## Typography

The display typography uses Google Fonts **Bangers** and **Permanent Marker** to echo the bold hand-painted lettering in the supplied BigGrillz LASGIDI artwork.
